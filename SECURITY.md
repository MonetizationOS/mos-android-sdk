# Security

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue or pull request for a security problem.

Include what you found, the SDK version and platform, and steps to reproduce it. We will acknowledge the report and work on a fix.

## Supported versions

Only the latest release gets security fixes.

## Scope

This repository holds the MonetizationOS Android SDK (`mos-core` and `mos-android`) and its example app. Problems in the MonetizationOS service itself are out of scope here.
